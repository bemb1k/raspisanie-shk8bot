# Telegram-бот расписания школы № 8

Проект проверяет страницу «Изменения в расписании» в Дневник.ру, находит ссылку в слове «ЗДЕСЬ», скачивает публичный PNG из Облака Mail и отправляет его в группу при появлении новой версии.

## Что уже настроено

- Источник: страница Дневника с заголовком «Изменения в расписании».
- Ссылка на Mail Cloud ищется каждый запуск заново, поэтому смена ссылки поддерживается.
- Для сравнения используется SHA-256 содержимого файла. Если ссылка поменялась, а PNG остался тем же, дубль не отправляется. Если PNG исправили по старой ссылке, новая версия отправится.
- Проверка расписана каждые 5 минут с 16:00 до 20:55 и ещё раз в 21:00, понедельник–суббота, часовой пояс Europe/Moscow.
- В воскресенье публикаций нет.
- Если за день не отправлено новое изображение, финальная проверка отправляет: «Расписания нет. Скорее всего без изменений.»
- Ошибка проверки отправляется владельцу бота в личный чат. Повторяющаяся без изменений ошибка не присылается каждые 5 минут.
- Изображение до 10 МБ отправляется как фото; более крупное — как файл Telegram, до 50 МБ.

## Важное о скачивании из Облака Mail

На момент подготовки инструкции публичная ссылка открывалась без входа в аккаунт и показывала PNG «23 окт 26.PNG» размером 73,5 КБ. Код использует публичный endpoint Облака Mail для получения временного адреса скачивания. Этот endpoint не является документированным публичным API Mail, поэтому Mail может поменять его работу. Если это случится, бот сообщит об ошибке лично, а не отправит HTML-страницу вместо расписания.

## 1. Подготовь бота и Telegram-группу

На присланном скриншоте уже открыт экран редактирования бота в BotFather.

1. Имя `Расписание` оставь как есть. Описание необязательно; если хочешь, впиши: `Изменения в расписании школы № 8`.
2. Посмотри на публичную ссылку. На скриншоте это `t.me/raspisanie_shk8_bot`, поэтому дальше используй имя `@raspisanie_shk8_bot`. Ранее было указано другое имя без подчёркивания перед `bot`; ориентируйся на ссылку, которая показана в BotFather.
3. Нажми **Сохранить** внизу.
4. Открой чат с `@BotFather`, отправь `/mybots`, выбери бота **Расписание** с публичной ссылкой `t.me/raspisanie_shk8_bot`, затем открой **API Token** (может отображаться как **Токен API**) и скопируй токен. Храни его в секрете: не присылай его сюда, в группу и не вставляй в исходный код.
5. Открой `@raspisanie_shk8_bot` по публичной ссылке и нажми **Start**. Это нужно, чтобы бот мог присылать тебе личные сообщения об ошибках.
6. Добавь `@raspisanie_shk8_bot` в школьную группу. Разреши ему отправлять сообщения и фотографии. Полные права администратора не нужны, если обычному участнику разрешено отправлять сообщения.
7. В группе отправь команду `/start@raspisanie_shk8_bot`. Это нужно, чтобы узнать ID группы.

## 2. Узнай ID личного чата и группы

На компьютере установи Python 3.10 или новее, если он ещё не установлен. Открой PowerShell, перейди в распакованную папку проекта и проверь Python:

```powershell
cd "$env:USERPROFILE\Downloads\raspisanie_bot"
py --version
```

Если команда `py --version` не сработала, установи Python с официального сайта python.org и при установке отметь добавление Python в PATH. Затем установи библиотеки:

```powershell
py -m pip install -r requirements.txt
```

Проверь чтение сайта и скачивание PNG. Эта команда не отправляет сообщения и не требует токена:

```powershell
py bot.py --source-only
```

В конце должно появиться сообщение `Файл скачан. Сообщения в Telegram не отправлялись.` Если эта проверка выдаёт ошибку, не переходи к настройке GitHub: сначала сохрани текст ошибки и попроси помочь исправить.

Запусти помощник:

```powershell
py get_ids.py
```

Вставь токен, полученный у `@BotFather`. Он будет отображаться в окне PowerShell во время ввода, поэтому никому не показывай это окно и не делай скриншот с токеном. Программа выведет ID личного чата и группы, а затем будет ждать нажатия Enter.

Если ID группы не появился, отправь в группе `/start@raspisanie_shk8_bot` и запусти `py get_ids.py` ещё раз.

## 3. Создай приватный репозиторий на GitHub

1. На github.com выбери **New repository**, введи имя `raspisanie-shk8bot` и выбери **Private**. Создай пустой репозиторий.
2. Установи GitHub Desktop с официального сайта desktop.github.com и войди в тот же аккаунт GitHub.
3. В GitHub Desktop открой **File → New repository**. Назови его `raspisanie-shk8bot` и выбери папку для локального репозитория, например `Documents\GitHub`.
4. Открой эту новую папку в Проводнике Windows. Скопируй в неё файлы из распакованной папки `raspisanie_bot`, включая `.github` и `.gitignore`.
5. Вернись в GitHub Desktop. В поле **Summary** напиши `Добавить бота расписания` и нажми **Commit to main**.
6. Нажми **Publish repository**. Проверь, что флажок **Keep this code private** включён, затем опубликуй.
7. Открой репозиторий на github.com. Убедись, что `bot.py` находится в корне, а workflow — по адресу `.github/workflows/schedule.yml`.
8. В GitHub открой **Settings → Actions → General → Workflow permissions**, выбери **Read and write permissions** и сохрани. Это нужно, чтобы бот записывал состояние отправок в `state.json`.

## 4. Добавь токен и ID как Secrets

В GitHub открой **Settings → Secrets and variables → Actions → New repository secret**. Создай три секрета:

| Имя | Что вставить |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от `@BotFather` |
| `TELEGRAM_GROUP_CHAT_ID` | ID школьной группы из `get_ids.py` |
| `TELEGRAM_OWNER_CHAT_ID` | Твой личный ID из `get_ids.py` |

Вставляй токен только в поле Secret GitHub. Не добавляй его в `bot.py`, README или обычный файл.

## 5. Проверь и включи автоматические запуски

1. Открой репозиторий → вкладка **Actions**. Если GitHub попросит разрешить workflow, нажми **Enable**.
2. Для первой проверки можно временно указать ID тестовой группы в секрете `TELEGRAM_GROUP_CHAT_ID`. В тестовую группу добавь бота и себя. Вкладка **Settings → Secrets and variables → Actions** позволяет удалить или изменить Secret.
3. Выбери **Проверка расписания → Run workflow**. Ручной запуск проверяет окно по московскому времени и отправляет изображение только с 16:00 до 21:00. Если запустишь workflow за пределами этого времени, он завершится без отправки.
4. Убедись, что изображение пришло в тестовую группу и запуск завершился без ошибки.
5. Замени `TELEGRAM_GROUP_CHAT_ID` на ID школьной группы и добавь туда бота. При необходимости запусти workflow ещё раз внутри окна 16:00–21:00.
6. Следующие запуски будут происходить автоматически. Компьютер для этого включённым держать не нужно.

Историю запусков и ошибки смотри в **Actions → Проверка расписания → выбранный запуск**. Если что-то не так, бот также напишет тебе лично, когда сможет связаться с Telegram.

## Изменение расписания проверки

В `.github/workflows/schedule.yml` заданы два запуска: каждые 5 минут с 16:00 до 20:55 и финальный запуск в 21:00 по Москве. Дни `1-6` означают понедельник–субботу. Время можно менять в этих строках cron; подробности синтаксиса есть в [документации GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#onschedule).
